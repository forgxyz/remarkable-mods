# remarkable-mods

Personal xovi QMD extensions for the reMarkable tablet.

## Extensions

- [`random-sleep-screen/`](./random-sleep-screen/) — Random sleep screen with on-device folder picker and a lightweight watcher that applies folder changes on-device
- [`lamy-eraser/`](./lamy-eraser/) — Maps the Lamy EMR pen button to eraser/undo/other actions
